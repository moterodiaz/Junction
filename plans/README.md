## Verdict (harsh, with evidence)

**Overall.** The *process* engineering is unusually strong for a hackathon: an
agent PR pipeline with review, a capped fixer and escalation; a contract with
recorded exchanges and a conformance harness; 147 backend unit tests including
privacy tests; a documented PRD that the code mostly cites. The *product truth*
is weak: the two headline features from PRD §2 — "a picture, not a paragraph"
and "sources for that book" — respectively **have never produced an image**
(wrong SDK method *and* a non-existent response field, swallowed silently) and
**are not wired into the pipeline at all** (574 lines of passage lookup with no
production caller; every session starts as *Hamlet*). The repo's public face is
someone else's project (template README, broken banner, no root LICENSE on a
public repo that must be MIT). Every model client is stubbed in every test, so
nothing that talks to Nemotron, Gemini or TTS has ever been exercised by CI.

**Google DeepMind — Best use of Gemini API.** Today's Gemini usage is: one
`generateContent` call with `responseMimeType: application/json` and no schema,
parsed with regex fence-stripping; an image call through the Imagen
(`generate_images`) surface that reads `response.images` (the SDK field is
`generated_images`) — so it has never worked; a TTS call on a legacy call shape
that has never run. The "memory that lasts the whole book" is a Q&A list
re-sent each turn; the 1M-token context the PRD gives as the reason for choosing
Gemini is unused; "act, scene, line" is the model's guess, and `sources` is a
hard-coded Gutenberg link. **As-is this would not place.** With plans 002 and
005 it becomes defensible: grounded citations from the loaded text,
deterministic location, structured output, three modalities that demonstrably run.

**NVIDIA — Best use of Nemotron.** The client is wired correctly
(OpenAI-compatible, `enable_thinking: false`, text out). But the only endpoint
the team can reach answers in **260–275 s**; the stage timeout is **25 s**; and
the open fallback PR (#99) gives Nemotron 8 s before Gemini reads the page. In
the live demo **Nemotron will never read a page**, and the card will say so
(`models.read`). The only accuracy number anyone has seen is the stub printing
`Overall Accuracy: 100.00%` at the end of every CI log. The mandatory submission
note names an endpoint the team does not use. **A judge asking "did Nemotron read
this?" gets "no".** Plan 006 makes the claim measured and truthful; the
direction notes suggest what would make it *strong*.

**Tieto — Earned trust in AI code.** The best-engineered part of the repo and
the least documented: **none** of the three mandatory deliverables exists, **0**
task issues or PRs carry a requirement ID, **nothing is measured**, and the
numbers that do exist are unflattering until explained — 44 of 69 AI review
threads (64%) were resolved without a word, 0 of 55 merged PRs have a human
approval, the escalation safety net (`pr-sweeper`) failed 84 times unnoticed,
the fixer's "never touches workflows / never merges" limits are prompt text that
nothing checks, and the merge-authority rule is stated five contradictory ways
across `AGENTS.md`, two guard hooks, a workflow comment and the pitch draft.
**Currently un-judgeable.** With plans 003, 004 and 007 it is a credible
first-place case precisely *because* the pipeline is real and the failures can
be documented honestly — judges reward measured limits over claimed perfection.

**Main prize — Implementation (33%).** README/LICENSE (plan 001), the image bug
(002), and an iOS decoder that rejects a valid contract message and turns it
into a fake 30-second timeout (009) are the three things most likely to embarrass
the team at the table.

### Direction (options for the maintainers, grounded in the repo)

- **D1 — Nemotron beyond OCR.** `page_reader.py:22-27` asks only for a verbatim
  transcript, which Gemini could do. Ask Nemotron for a small JSON — `text`,
  `is_book_page`, `speakers`, `stage_directions`, `page_number`, `legibility` —
  and use `speakers` to label the explanation ("Hamlet, alone") and `is_book_page`
  to drive the "that's not a page" state (PRD §6). That is a *reason* to use a
  VL model, not just the sponsor's model. Effort M; trade-off: latency on an
  already slow endpoint, so pair it with D3.
- **D2 — Whole-book long context, for real.** PRD §2/§4 sell the 1M context;
  `hamlet.json` (1 MB) is loaded and indexed but never sent. After plan 005, put
  the *whole play* in the prompt with Gemini context caching keyed by
  `session_id` (docs: ai.google.dev/gemini-api/docs/long-context). Effort M;
  trade-off: tokens and first-call latency; measure with plan 006's harness.
- **D3 — Reader agreement as a published metric.** With #99 the backend has two
  page readers. Record Nemotron-vs-Gemini word agreement per frame in
  `measure_accuracy.py` and show it on the Nemotron slide ("Nemotron agrees with
  the fallback on 97% of words; we use it as the ground-truth reader offline").
  Effort S after plan 006. Do **not** do this live by retaining frames — it
  breaks REQ-PRIV-01 unless the PRD changes.
- **D4 — The pipeline *is* a product.** `tools/board`, `tools/task`, `claude-fix`,
  the sweeper, the conformance harness and (after plans 003/004/007) the metrics
  and header make a reusable "bounded autonomy" kit. Plans 003/004 already write
  the case; the README (plan 001) should give it a section with a link.

### Considered and rejected / not now

- **Dependency caching in CI** — the whole `ci` job is ≈1 m 54 s; not worth it.
- **gitleaks job** — public repo; GitHub secret scanning + push protection are on
  by default; check Settings → Code security instead of adding a job.
- **Unifying the two guard hooks into one policy** (finding 19, M effort) —
  right after the hackathon; before it, state the rule once (003) and enforce the
  protected paths in the workflow (007).
- **Full session/image/clip eviction redesign** (finding 21) — a single-container
  one-day demo will not hit it; the history cap in 005 covers the cost growth.
- **Dead code**: `asgi_image_app` (`image.py:487-516`), the urllib fallback in
  `page_reader._send_request` (httpx is a hard dependency), `ai/__init__.py:56-60`
  re-import, `tools/_chaos/*.txt`, the dropped `Cache-Control` header
  (`image.py:466,481`) — cosmetic; leave until after submission.
- **Lockfile for backend deps** — recommended (finding 10) but deferred behind
  the Python pin; `uv pip compile --python-version 3.12` when someone has 20 minutes.
- **`required_approving_review_count` → 1** — would slow a 4-person team to a
  crawl with 21 h left; keep 0, enforce protected paths in the workflow, and say so
  in the concept card's limits.

runtime accounting of long-lived WebSocket inputs; performance under concurrent
load; dependency CVEs (`pip-audit` was not run); the Gemini/Nemotron services'
real responses (no keys were used in this audit).
